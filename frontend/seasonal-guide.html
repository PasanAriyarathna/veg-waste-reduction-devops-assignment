🌾 Sri Lanka Cultivation & Harvest Guide

Practical insights into vegetable seasons, growing areas, post-harvest management, and agricultural resources

📅 National Cultivation Seasons

Sri Lanka follows two main national cultivation seasons linked with monsoon patterns. Vegetables are grown in both seasons, but planting and harvest timing vary based on agro-climatic zones, irrigation availability, and local rainfall patterns.

🌧️ Maha Season

Duration: September → March

Linked with: North-East monsoon

Characteristics:

  • Primary cultivation season across Sri Lanka
  • Peak planting and harvesting period
  • Up-country vegetables flourish due to cooler temperatures
  • Favorable rainfall for rain-fed agriculture

☀️ Yala Season

Duration: May → End of August

Linked with: Dry period (SW monsoon influence)

Characteristics:

  • Heavily irrigation-dependent season
  • Strong production in low-country zones
  • Suitable for warm-climate vegetables
  • Inter-season cultivation in some areas

⚠️ Important Note: Some areas practice short "inter-season" cultivation (April-May, September) between Maha and Yala, using stored soil moisture and early rains. Actual planting and harvest timing varies significantly by district based on local climate patterns.

📍 Major Vegetable Growing Zones

Cultivation patterns vary by agro-climatic zone. Sri Lanka is divided into Up-country, Mid-country, and Low-country regions with distinct climate and irrigation profiles. Additionally, rainfall pattern classifications (Wet, Intermediate, Dry zones) influence farming practices.

❄️ Up-Country (Cool Climate Belt)

Prime Vegetable Production Hub: These regions account for the largest share of seasonal vegetable cultivation nationally, with Badulla, Kandy, and Matale highlighted as leading agricultural districts.

Common Loss Causes

🚚 Transport Damage

Poor packaging and over-stacking during transportation causes significant losses across the supply chain. Inadequate containers and rough handling contribute heavily.

🌡️ Temperature Exposure

Lack of cold chain infrastructure leads to spoilage, especially in warm climates of low-country zones. Many vegetables require temperature-controlled storage and transport.

🏪 Wholesale/Retail Handling

Poor storage practices and handling at markets and retail points contribute significantly to quality degradation. Extended display times without proper cooling increase losses.

📦 Inadequate Storage

Insufficient storage facilities with improper temperature and humidity control accelerate deterioration. Farm-level storage is often basic and inadequate.

🐛 Pest & Disease

Post-harvest pests and fungal diseases thrive without proper storage management. Lack of fumigation and pest control measures increases losses.

⏰ Time Delays

Extended time between harvest and market sale, especially in remote areas, leads to quality loss. Poor market access and transportation networks increase delays.

🎯 Opportunity: Improving post-harvest management, cold chain infrastructure, proper packaging, and farmer training could reduce losses by 10-15%, significantly boosting farmer income and food availability.

🔗 Agricultural Data Sources & APIs

Several official sources provide agricultural data that can enhance your platform with real, production data.

A) DOA CROPIX Platform (Recommended)

🏛️ Department of Agriculture (DOA) CROPIX

Status: Official open data platform for Sri Lankan agriculture

What it provides: Crop production data, district-wise cultivation statistics, monthly production reports, seasonal targets, crop-specific information

How to integrate:

// Example API structure (requires DOA registration) GET /api/crops?district=Badulla&season=Maha&year=2025 GET /api/production?crop=Potato&district=Nuwara%20Eliya&month=January GET /api/seasonal-targets?zone=UpCountry

Next Steps:

  • Register at DOA CROPIX platform
  • Request API access (auth token)
  • Implement district-wise production fetching
  • Cache data locally for performance

B) Sri Lanka Open Data Portal

📊 data.gov.lk (DKAN API)

Status: National open data repository

Available datasets: Agricultural statistics, harvest data, district information, seasonal reports

API Structure:

GET https://data.gov.lk/api/3/action/datastore_search?resource_id=RESOURCE_ID GET https://data.gov.lk/api/3/action/package_list

Note: Some endpoints may experience availability issues (502 errors). Use as backup source.

Recommended Data Integration Approach

📈 District-wise Monthly Production

  • Fetch via DOA CROPIX API

🛠️ Implementation Guidance for Your Platform

To integrate real agricultural data into your VegWaste platform:

Step 1: Register with DOA CROPIX

  • Visit DOA CROPIX registration page
  • Apply for API access token
  • Document base URL and authentication method
  • Test API endpoints in staging environment

Step 2: Update Node.js Backend

Create API endpoints that fetch and cache DOA data:

// server.js - New endpoint for district production app.get('/api/district-production/:district/:season/:year', async (req, res) => { try { const { district, season, year } = req.params; // Check cache first const cached = cache.get(`production_${district}_${season}_${year}`); if (cached) return res.json(cached); // Fetch from DOA CROPIX API const response = await fetch(`${DOA_API}/production`, { headers: { 'Authorization': `Bearer ${DOA_TOKEN}` }, qs: { district, season, year } }); const data = await response.json(); cache.set(`production_${district}_${season}_${year}`, data); res.json(data); } catch (error) { res.status(500).json({ error: error.message }); } });

Step 3: Update Frontend Display

Fetch and display data on seasonal-tracking page:

// Fetch real production data fetch('/api/district-production/Badulla/maha/2025') .then(r => r.json()) .then(data => { updateDistrictCard('Badulla', data.production); updateMapMarkers(data); });

Step 4: Add Real-Time Updates

  • Schedule API calls for monthly data refresh
  • Display "Last Updated" timestamp
  • Show actual vs target comparison
  • Alert users about significant variations
